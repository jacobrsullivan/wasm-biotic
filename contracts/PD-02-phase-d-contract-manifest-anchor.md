# PD-02 Phase D Contract Manifest Anchor

This anchor freezes the first concrete manifest shape for the live local-first Phase D exchange-contract line.

It is downstream of the `PD-01` anchor family and should be read as:

- one concrete manifest form,
- for one bounded pre-federation exchange line,
- that remains attributable to `PD-01`,
- and does not authorize federation or remote orchestration.

## Required fields

- `manifest_id`
- `anchor_family_ref`
- `manifest_schema_ref`
- `sender_identity_refs`
- `envelope_refs`
- `compatibility_refs`
- `quarantine_refs`
- `imported_content_refs`
- `claim_boundary`

## Frozen meaning

- `anchor_family_ref` must cite the `PD-01` anchor-family manifest.
- `manifest_schema_ref` must cite the frozen concrete schema file for this manifest line.
- `sender_identity_refs`, `envelope_refs`, and `compatibility_refs` must remain attributable to explicit stored Phase D records.
- `quarantine_refs` must remain present whenever imported content stays reviewable under quarantine-first law.
- `imported_content_refs` may point to lineage imports and bounded memory packets only.
- `claim_boundary` must preserve local-first pre-federation language.

## Boundary statement

This concrete manifest proves one bounded Phase D contract-export line for local-first exchange review. It does not prove federation, ambient trust, or ecosystem autonomy.
