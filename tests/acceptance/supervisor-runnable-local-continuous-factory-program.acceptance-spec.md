# Acceptance Spec: `supervisor-runnable-local-continuous-factory-program`

This scenario validates the integrated `v1.5` local runnable surface.

Expected behavior:

- a curated local continuous-program demo can be started,
- the operator surface can resume it to completion,
- the run remains exportable as a durable local bundle,
- and the resulting report retains the continuous self-hosting framing under the same stable `v1` kernel contract.
