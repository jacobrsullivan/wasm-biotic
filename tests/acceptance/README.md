# Acceptance Tests

This folder contains the canonical integrated scenarios for standalone `aiaf-v1`.

The acceptance tree carries the bounded operator, LLM-interface, recursive-factory, NorthStar, and substrate lines for the live root package. It is intentionally broader than the curated runner surface and now includes a dedicated `Factory_01` LLM operator lane.

The acceptance tree is intentionally broader than the curated runner surface. Only eleven scenarios are exposed through `aiaf-v1-runner`; the rest exercise kernel invariants, bundle generation, HTTP operator flows, and operator/readout workspaces directly in Rust.

The later `v2.x` labels in this folder refer to operator/readout and transition-readiness lines layered over the stable `aiaf_v1::execution` contract. They are not claims that the full Wasm-Biotic northstar already exists as a separate live Wasm/WIT runtime in the root package.

The folder now also carries implemented `v3` acceptance coverage for the post-`v2` line:

- `supervisor-v3-generation-artifact-packaging`
- `supervisor-v3-native-service-validation-closure`
- `supervisor-v3-generation-comparison-adoption-rollback`
- `supervisor-v3-adopted-generation-successor-production`
- `supervisor-v3-self-production-workspace`
- `supervisor-v3-bounded-single-factory-self-production-gate`
- `supervisor-v3-northstar-complete-substrate-gate`

These `v3` paths are part of the current acceptance surface. A static source inventory finds `218` Rust test attributes under `tests/acceptance/`; that number describes source coverage, not the result of a latest green run.
